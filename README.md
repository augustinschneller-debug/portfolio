# portfolio

Site web portfolio d'Augustin Schneller (EPITA), en HTML, CSS et JavaScript, sans framework ni build.

- `index.html` : contenu (parcours, projets, labo interactif, expérience, compétences, perspectives, contact)
- `style.css` : mise en page, thème sombre et clair, responsive
- `script.js` : interactions (thème, filtres, fenêtres de détail, simulations réseau, onglets)
- `img/` : images

Ouvrir `index.html` dans un navigateur suffit. Pour le publier, GitHub Pages fonctionne directement depuis la branche `main`.
